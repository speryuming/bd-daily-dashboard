# 福泉整改跟进系统

局域网多人使用的整改跟进工具。数据保存在运行服务的 Mac 上，市场人员与管理人员使用各自账号登录。

## 启动与访问

1. 在作为服务端的 Mac 上双击 `启动多人访问.command`。
2. 终端会显示局域网地址，例如 `http://192.168.100.103:8765/`。
3. 把该地址发给连接同一 Wi-Fi 或局域网的市场人员。
4. 保持这台 Mac 开机、联网，且不要关闭启动服务的终端窗口。

首次启动如果 macOS 询问是否允许 Python 接受传入网络连接，请选择“允许”。双击 `停止整改跟进.command` 可停止服务。原来的 `启动整改跟进.command` 也会启动多人版。

## 账号与权限

- 管理人员：导入问题表、添加账号、分派负责人、人工映射店铺、填写整改反馈、次日复核。
- 市场人员：查看问题清单，只能对分配给自己的问题提交晚间整改反馈。
- 只有管理人员可以提交复核结果，后端接口也会校验权限。
- 每个人使用自己的账号；操作记录自动使用登录人员姓名。登录 12 小时后需重新登录。

原系统中的首位管理账号会自动保留。管理人员登录后，点击右上角账号入口，可添加市场人员或其他管理人员账号。密码至少 10 个字符，并以加盐哈希保存。

如果忘记密码，可在服务端 Mac 上双击 `重置账号密码.command`。工具会在终端中隐藏输入新密码，也可以同时修正登录账号；密码不会显示或发送到网络。

## 每天怎么用

1. 管理人员可在“添加问题”中手动填写单条问题，或者上传现有运营表批量导入。
2. 管理人员为每条问题选择一个已创建的人员账号并设置截止日期。
3. 负责人晚上登录，填写整改动作、说明和证据链接或文件名。
4. 次日管理人员登录复核。未通过的问题回到“待反馈”，通过后关闭。
5. 店铺映射可以后补；系统不会按两个平台不同的店名自动配对。

## 数据与维护

- 数据库：`data/rectification.sqlite3`
- 上传文件：`data/uploads/`
- 默认端口：`8765`
- 备份时复制整个 `data/` 文件夹，建议先停止服务。
- 当前方案用于可信任的内部局域网。不要在路由器上把 8765 端口开放到互联网。
- 如果服务端 Mac 的局域网地址变化，重新双击启动脚本即可看到新地址。

命令行启动方式：

```bash
python3 app.py --host 0.0.0.0 --port 8765
```

## 公网部署

`render.yaml` 用于部署到 Render 免费网页服务。部署时需要设置 Turso 数据库地址和令牌，以及首位管理人员的账号、姓名和密码。上传工作簿只在解析期间临时保存，问题记录写入 Turso 云数据库。`data/` 已被排除，不会上传现有数据库、密码哈希或工作簿。
